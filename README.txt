Be sure to extract the ZIP file before starting!

1. Run `setup.bat`.
2. Follow the instructions in the guide.

The guide will have a shortcut created inside `rust_server`
under the name `Full Guide Here - Open Me If Lost`.

You can also open it manually:
`guide\open_me.html`

### Automatic Updates

The package includes `setup_updater.bat`, which checks GitHub for new versions of the server package.

Every time you launch `start_server.bat`, it automatically checks if a newer package version is available.

If an update is available, you will be asked if you want to install it.

The updater only updates the package files and guide. It does not modify:

* `rust_server\server_files`
* `start_server.bat`

You can also run `setup_updater.bat` manually at any time to check for and install package updates.

Requirements:

* Windows
* Internet connection
* Web browser

The setup will automatically install the required files and tools.
