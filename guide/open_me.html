Rust Server Guide

Install, start and configure your own Rust dedicated server on Windows.

1 Setup

Everything is installed automatically by setup.bat. You only have to run it once.

Install the server

Download SteamCMD and the Rust dedicated server files.

  1. Run setup.bat

  2. Wait for the download to finish

    The script downloads SteamCMD and the Rust dedicated server files. This can take a while. Do not close the window.

  3. Wait for «Setup finished!»

    When you see Setup finished!, press any key to close the window. Your server is now installed.

Check the installed files

Your batch files are stored inside rust_server. 

RustServer/
├── setup.bat
├── steamcmd/
└── rust_server/
    ├── start_server.bat
    ├── update_oxide.bat
    ├── select_version.bat
    └── server_files/
Good to know: setup.bat only installs the vanilla Rust server. Oxide can be installed later with update_oxide.bat. See Chapter 4 → Oxide for more information.

2 Start the server

Once the setup is finished, choose how you want to continue.

Choose how to continue

You can start immediately or configure the server first.

Option A

Start right away

Launch start_server.bat with the default settings.

Option B

Configure first

Install Oxide, choose a version or customize the map before launching.

Start the server

Launch the server and wait until it finishes loading.

  1. Open the rust_server folder

    Double-click start_server.bat.

  2. Wait for the server to load

    A console window opens and generates the map on the first launch. This can take a few minutes.

    Keep this window open: closing it stops the server.

Connect to your server

Connect locally using the Rust F1 console.

Launch Rust or Rust Staging depending on the version you installed. Press F1 to open the game console and enter:
client.connect localhost

Make yourself admin

Give your player server administrator permissions.

Go to Chapter 3 → Commands to configure your SteamID and admin commands.

3 Commands

Fill in your information once, then copy the generated commands.

Player information

Enter the Steam information used by the commands below.

Server administrator

Give yourself Rust server administrator permissions.

Some commands require privileges. If you cannot execute them from the game console, use the server console.
Run this command with your SteamID and username:
ownerid YOUR_STEAMID64 YOUR_STEAM_USERNAME
Save the change
Run this afterwards so the admin list is kept after a restart.
server.writecfg

Oxide commands

Check Oxide and configure its administrator group.

Check if Oxide is installed

If the command is unknown, Oxide is not installed yet.
oxide.version

Grant access to the admin group

Give the Oxide admin group access to every permission.
oxide.grant group admin *

Grant all permission to a User

Give the Oxide User access to every permission.
oxide.grant user YOUR_STEAM_USERNAME *

Add yourself to the admin group

Add the player from the information above to the Oxide admin group.
oxide.usergroup add YOUR_STEAM_USERNAME admin

Install or update Oxide

Install the modding framework required for Rust plugins.

What is Oxide? Oxide (uMod) is the modding framework used to run Rust plugins. If you only want a completely vanilla server, you do not need it.

  1. Stop the server

    Close the server console or type quit.

  2. Run update_oxide.bat

    Double-click the file inside your rust_server folder.

  3. Wait for the update to finish

    Wait until the script reports: Oxide update finished successfully.

  4. Start the server again

    Launch start_server.bat and verify the installation with oxide.version.

Choose the Rust version

Switch between the Main, Staging and Beta branches.

How to change the version 3 steps
1 Stop the server.
2 Run select_version.bat.
3 Select the branch and wait for SteamCMD.

Branches:
1
Main PUBLIC

The normal public Rust version. This is the standard choice for a regular server.

Works with Oxide.
2
Staging TESTING

The upcoming Rust version used for testing before changes reach the public branch.

May not work with Oxide.
3
Public Beta BETA

Enter the name of a public beta branch when prompted by the script.

May not work with Oxide.
4
Private Beta BETA

Enter the branch name and its password when prompted by the script.

May not work with Oxide.
5
Exit

Close the menu without changing anything.

Important: If you change the Rust version, run update_oxide.bat again afterwards. Changing branches can overwrite Oxide files.

Server settings

Change how the server starts and which map it loads.

For this, you will need to edit your start_server.bat file.

STARTUP CONFIGURATION
EDIT
Your start_server.bat should look like this:
@echo off cd ./server_files/ RustDedicated.exe ^ -batchmode ^ +server.level "Procedural Map" ^ +server.seed 2147483647 ^ +server.worldsize 1000 ^ +server.maxplayers 10
^ = new line

MAP TYPE

Procedural Map

Let Rust generate a map automatically using a seed and world size.

Keep these settings:
+server.level "Procedural Map" +server.seed 2147483647 +server.worldsize 1000
Seed Controls which procedural map is generated.
World size Controls the size of the generated map.
MAP TYPE

Custom Map

Use an existing Rust custom map instead of generating a procedural map.

Get the map from a server

If you are playing on a server that uses a custom map, you can check which map the server is using from the Rust F1 console.

  1. Join the server

    Connect to the Rust server whose map you want to obtain.

  2. Open the F1 console

    Press F1 while you are connected to the server.

  3. Check the server information

    Use the F1 console to inspect the server information and identify the map being used.

Use the map on your server

Once you have a direct URL to the .map file, put it in your start_server.bat.
Use:
+server.levelurl "https://maps.rustmaps.com/288/e9ba372f1b224bde83ce68f7ce591864/procedural__4555_55mQZn0PsUm6EKRCl0x3GQ.map"
Do not keep both configurations. When using a custom map, remove the procedural map settings:

+server.level +server.seed +server.worldsize

Your startup configuration should use +server.levelurl instead.
If you're a content creator, Custom Maps are perfect for creating cinematics on the same map where you recorded your gameplay.

5 Server files

Everything related to the actual Rust server is stored inside server_files.

Server folder structure

The server executable and its data are stored here. 

rust_server/
└── server_files/
    ├── RustDedicated.exe
    ├── RustDedicated_Data/
    ├── server/
    └── oxide/
        ├── plugins/
        ├── config/
        ├── data/
        └── logs/

Important files

The files you will interact with most often.

start_server.bat

Starts the Rust dedicated server using your configured settings.

update_oxide.bat

Installs or updates Oxide after Rust updates.

select_version.bat

Switches between Rust server branches.

RustDedicated.exe

The main executable used to run the dedicated server.

Good to know

A few things to keep in mind when browsing the files.

  • Everything the server needs is inside server_files.
  • The batch files stay next to server_files.
  • Some folders only appear after the first launch or after installing Oxide.
